# Plan 00-02: Dashboard UI Overhaul

## Objective

Rewrite the Vue 3 SPA dashboard to implement:
1. **Task abstraction fix** — Show only Tasks on the Kanban board (no flattened subtasks)
2. **Jira-style cards** — Progress bar, rollup stats, priority badge, deadline, comment count
3. **Task detail panel** — Right sidebar with subtask list, inline hours entry, comments thread
4. **Global overview + phase tabs** — Default landing page shows all phases; tabs filter to one phase
5. **Three charts** — Burndown (inline SVG), hours comparison, weekly trend
6. **Comments UI** — Comment count bubbles on cards, full thread in detail panel

#### 7. SVG Burndown Chart (D-18)
Inline SVG, no external libraries:
- X axis: today to target_completion date (from tasks.json project)
- Y axis: total_estimated_hours (top) to 0 (bottom)
- **Ideal line**: straight from (today, total_remaining) to (deadline, 0)
  - total_remaining = sum of estimated_hours for all incomplete tasks across all phases
- **Actual line**: points computed from hours_summed (estimated) minus logged for completed tasks
  - Plot actual remaining hours for each past day based on task completions logged in git history
  - For simplicity: plot a single point "today" showing current remaining hours
- Chart dimensions: responsive, ~600x200, with axis labels
- Legend: "Ideal" (dim dashed line), "Actual" (solid accent line)

#### 8. Hours Comparison (D-18)

### Key Computed Properties:

```javascript
// Flat list of tasks only (no subtasks) for the current phase
const phaseTasks = computed(() => {
  const phase = tasks.value.phases?.find(p => p.id === activePhaseId.value);
  if (!phase) return [];
  return phase.tasks || [];
});

// Subtask rollup per task
const taskProgress = (task) => {
  const subs = task.subtasks || [];
  const done = subs.filter(s => s.status === 'done').length;
  return { total: subs.length, done, percent: subs.length ? Math.round(done/subs.length*100) : 0 };
};

// Unread comment count per task
const unreadCommentCount = (taskId) => {
  return comments.value.filter(c => c.task_id === taskId && !c.read).length;
};
```
