### Task 00-03-3: Add "comments" command to list unread comments

<read_first>
- `.pam/cli.sh` — To understand the dispatch pattern and existing command structure
- `.pam/comments.json` — Comments data file (from Plan 00-01)
- `.pam/tasks.json` — For looking up task names by task_id
- `.planning/phases/00-pam-dashboard/00-CONTEXT.md` — D-24 (agent checks read:false at session start)
</read_first>

<action>
Add a new `comments()` function and wire it into the dispatch and help:

```bash
comments() {
  local unread
  if command -v jq &> /dev/null; then
    unread=$(cat "$PAM_DIR/comments.json" | jq -r '.comments[] | select(.read == false) | "  [\(.category)] \(.task_id): \(.text | .[0:80])\(if (.text | length) > 80 then "..." else "" end)"')
    local count
    count=$(cat "$PAM_DIR/comments.json" | jq '[.comments[] | select(.read == false)] | length')
    echo ""
    echo -e "${CYAN}══════════════════════════════════════════${NC}"
    echo -e "${CYAN}  Unread Comments (${count})${NC}"
    echo -e "${CYAN}══════════════════════════════════════════${NC}"
    if [ "$count" -gt 0 ]; then
      echo "$unread"
      echo ""
      echo -e "${YELLOW}After reviewing, mark as read:${NC}"
      echo -e "${DIM}  jq '(.comments[] | select(.read == false) | .read) = true' ${PAM_DIR}/comments.json > tmp && mv tmp ${PAM_DIR}/comments.json${NC}"
    else
      echo -e "  ${GREEN}No unread comments.${NC}"
    fi
  else
    echo -e "${YELLOW}jq required for comments.${NC}"
  fi
  echo ""
}
```

Wire into dispatch:
```bash
comments|cmt)
  comments
  ;;
```

Add to help:
```bash
echo "  comments     List unread comments from AI agent notes"
```
</action>

<acceptance_criteria>
- `bash .pam/cli.sh comments` runs without errors
- If no unread comments: shows "No unread comments"
- If unread comments exist: shows category-badged list with task_id, truncating text to 80 chars
- `bash .pam/cli.sh help` shows the `comments` command
- `bash .pam/cli.sh cmt` works as alias
</acceptance_criteria>
